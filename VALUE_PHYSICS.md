# Value Physics

Value Physics is the mathematical foundation of ECO Co-SMOS's evaluation system. It replaces "likes" and "upvotes" with a set of dynamic metrics.

## Key Metrics

| Metric | Description |
| :--- | :--- |
| **Knowledge Energy** | The total activity and resonance associated with a node. |
| **Knowledge Momentum** | The rate of change in a node's resonance and application. |
| **Knowledge Potential** | The estimated impact a node could have on related clusters. |
| **Knowledge Entropy** | The measure of fragmentation or confusion surrounding a concept. |
| **Knowledge Activation** | The threshold required for a node to transition to a 'Practice' or 'Behavior'. |
| **Knowledge Dormancy** | The rate at which a node's active resonance decays. |
| **Knowledge Regeneration** | The ability of a node to be reconstructed from dormant parts. |
| **Knowledge Resonance** | The degree to which a node influences other nodes across distances in the semantic graph. |

## Dynamic Recalculation

These values are not static. They are updated by the **Value Physics Engine** whenever an event (application, discussion, experiment) occurs. The goal is to identify knowledge with high **Potential** but low current **Energy**.
