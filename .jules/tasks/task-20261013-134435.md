PHASE L continues with L-02: Epistemic Isolation Proxy (EIP).

Mission:
    Create a boundary between RAW experimental/tool observations
    and CANONICAL knowledge.

    Raw observations MUST NOT automatically become facts.
    Observations MUST have explicit provenance.
    Corrections MUST preserve original record (append-only).
    Conflicts MUST be flagged, not auto-resolved.

CRITICAL — EPISTEMIC PRINCIPLES:

    1. Provenance ≠ Evidence
       provenance describes source, method, path of data.
       Its presence does NOT confirm truth of measurement.

    2. Epistemic status ≠ interpretation of truth
       UNVALIDATED_OBSERVATION = default.
       PARTIAL, CONTRADICTION_SIGNAL, OBSERVATION_CORRECTED
       MUST NOT be set merely because values differ.

    3. Append-only
       NO update / delete of Observation.
       Corrections create NEW record with:
           supersedes_observation_id (FK, nullable)
           correction_reason (String, required on correction)

    4. Future-safe
       experiment_run_id — nullable String, NO FK.
       L-03 will introduce ExperimentRun model.
       L-02 does NOT create Experiment model.

    class Observation(Base):
        __tablename__ = "observations"

        id = Column(Integer, primary_key=True, index=True)

        # WHAT
        metric_name = Column(String, nullable=False, index=True)
        metric_value = Column(JSON, nullable=False)
        metric_unit = Column(String, nullable=True)

        # WHERE FROM (provenance, NOT evidence)
        tool_blueprint_id = Column(String, nullable=True, index=True)
        tool_id = Column(String, nullable=True)
        experiment_run_id = Column(String, nullable=True, index=True)
        execution_id = Column(
            Integer,
            ForeignKey("recipe_executions.id"),
            nullable=True,
        )

        # CONTEXT (references only, NOT evidence)
        hypothesis_refs = Column(JSON, default=list)     # List[int]
        prediction_refs = Column(JSON, default=list)     # List[int]
        assumption_refs = Column(JSON, default=list)     # List[str]
        phenomenon_refs = Column(JSON, default=list)     # List[int]

        # EXECUTION CONDITIONS
        execution_conditions = Column(JSON, default=dict)
        observed_at = Column(DateTime(timezone=True), nullable=False)
        created_at = Column(
            DateTime(timezone=True),
            server_default=func.now(),
        )

        # EPISTEMIC CLASSIFICATION (metadata only)
        epistemic_classification = Column(
            String,
            default="UNVALIDATED_OBSERVATION",
        )
        # Values:
        #   UNVALIDATED_OBSERVATION  (default)
        #   PARTIAL                  (incomplete)
        #   CONTRADICTION_SIGNAL     (conflicts with another observation)
        #   OBSERVATION_CORRECTED    (correction chain link)

        # PROVENANCE (metadata, NOT evidence)
        provenance = Column(JSON, default=dict)

        # DEDUPLICATION
        payload_hash = Column(String, nullable=True, index=True)

        # CORRECTION CHAIN
        supersedes_observation_id = Column(
            Integer,
            ForeignKey("observations.id"),
            nullable=True,
        )
        correction_reason = Column(String, nullable=True)

3. CRITICAL INVARIANTS
============================================================

INVARIANT 1 — APPEND-ONLY
    - Observation model: no update/delete.
    - Service: no update/delete methods.
    - Corrections create NEW record with correction chain.
    - Original record preserved forever.

INVARIANT 2 — PROVENANCE ≠ EVIDENCE
    - provenance JSON describes source, method, path.
    - Its presence or hash does NOT confirm truth.
    - Documentation in docstrings MUST state this.

INVARIANT 3 — EPISTEMIC STATUS ≠ INTERPRETATION
    - Default = "UNVALIDATED_OBSERVATION".
    - "PARTIAL" set only when explicitly declared (e.g.
      missing fields flagged).
    - "CONTRADICTION_SIGNAL" set only when explicitly
      requested (not auto-detected).
    - "OBSERVATION_CORRECTED" set only on records that are
      linked via correction chain.
    - Value difference does NOT auto-set classification.

INVARIANT 4 — EXPERIMENT_RUN_ID TEMPORARY
    - nullable String, NO FK.
    - L-03 will introduce ExperimentRun model.
    - L-02 does NOT create Experiment model.
