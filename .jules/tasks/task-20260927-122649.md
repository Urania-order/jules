============================================================
OBJECTIVE
============================================================

Define canonical Four-Position Analysis contract.

The Four-Position Analysis expresses four modal views of one Phenomenon₀:

    Position I    (PRESENT_EXISTS)
        "IF PRESENT -> WHAT EXISTS?"
        If the phenomenon emerges, what will exist?

    Position II   (ABSENT_ABSENT)
        "IF ABSENT -> WHAT DOES NOT EXIST?"
        If the phenomenon does not emerge, what will NOT exist?

    Position III  (ABSENT_EXISTS)
        "IF ABSENT -> WHAT EXISTS?"
        If the phenomenon does not emerge, what will exist instead?

    Position IV   (PRESENT_ABSENT)
        "IF PRESENT -> WHAT DOES NOT EXIST?"
        If the phenomenon emerges, what will NOT exist (what will it displace)?

CRITICAL RULES:

1. The four positions are PROJECTIONS of one Phenomenon₀, NOT four
   distinct Phenomena.

2. The Four-Position Analysis MUST reference the source Phenomenon₀
   by id (phenomenon_id).

3. The Four-Position Analysis MUST NOT auto-create:
   - new Phenomenon
   - new DomainRelation
   - new Prediction
   - fact promotion

4. Each position carries:
   - phenomenon_id
   - position (enum)
   - claim
   - evidence (list of references)
   - context (list of context_ids)
   - provenance (dict)
   - epistemic_status (default HYPOTHESIZED)
   - confidence (0.0-1.0, optional)

5. Each position is a MODAL / HYPOTHETICAL statement, NOT a fact.

6. Four-Position Analysis is NOT a Prediction:
   - Four-Position: "if X, then what?"
   - Prediction: "system expects X to happen under stated conditions"

7. Four-Position Analysis is NOT a Recipe/Learning Evidence:
   - Four-Position: modal projection of a phenomenon
   - Learning Evidence: historical analytical evidence trail

- positions MUST be a dict with keys exactly:
    PRESENT_EXISTS, ABSENT_ABSENT, ABSENT_EXISTS, PRESENT_ABSENT

    claim, confidence, evidence, context, provenance, epistemic_status
- claim (if present) MUST be a non-empty string.
- confidence (if present) MUST be a float in [0, 1].
- evidence / context MUST be lists of ints.
- provenance MUST be a dict.
- epistemic_status MUST be in {HYPOTHESIZED, INFERRED, PREDICTED,
                               UNVALIDATED, CONTESTED, REFUTED, OBSERVED}
  BUT: default is HYPOTHESIZED and tests only require HYPOTHESIZED.

INVALID cases (reject):
- missing positions dict
- unknown position keys
- position not a dict
- claim present but empty
- confidence out of range
- evidence/context not list of ints
- provenance not a dict
