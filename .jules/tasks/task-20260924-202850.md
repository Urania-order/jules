============================================================
DETECTION LOGIC (minimal, read-only)
============================================================

Group exposures by normalized claim.

For each group with >= min_agents exposures:

1. Conclusions match: already (group by claim).

2. Different roles present:
   roles = {e.role for e in group if e.role}
   agent_types = {e.agent_type for e in group}
   different_roles = len(roles) >= 2 OR len(agent_types) >= 2

3. Independent trajectories:
   For at least one pair (e1, e2) in group:
       jaccard(e1.context_ids, e2.context_ids) <= max_context_overlap
   AND
       (e1.role != e2.role) OR (e1.agent_type != e2.agent_type)

4. Confidence:
   confidences = [e.conclusion.get("confidence") for e in group
                  if isinstance(e.conclusion.get("confidence"), (int, float))]
   base = sum(confidences) / len(confidences) if confidences else 0.5
   scaled = min(1.0, base * (len(group) / max(min_agents, 1)) ** 0.5)
   # Confidence is a RESONANCE SCORE — NOT truth.

5. shared_context = intersection of all e.context_ids in group.

6. independent_contexts = [sorted(e.context_ids) for e in group].

7. Build ResonanceCandidate:
   kind = "candidate_resonance"
   supporting_trajectories = [
       {"agent_type": str(e.agent_type.value if isinstance(e.agent_type, AgentType) else e.agent_type),
        "agent_id": e.agent_id,
        "role": e.role}
       for e in group
   ]
   converging_conclusion = the matched conclusion JSON (first).
   epistemic_status = EpistemicStatus.HYPOTHESIZED.value  # NEVER OBSERVED
