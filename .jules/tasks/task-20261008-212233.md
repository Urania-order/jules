============================================================
CRITICAL ARCHITECTURAL PRINCIPLE
============================================================

Semantic retrieval is a PROPERTY OF THE PHENOMENON INVESTIGATION,
NOT a property of any individual Four-Position.

The retrieval is:
    semantic_service.similar("phenomenon", phenomenon_id, ...)

It retrieves semantic neighbors of the PHENOMENON.
It does NOT retrieve semantic neighbors of Position I/II/III/IV.

Therefore:
    semantic_candidates belong in
        analysis["provenance"]["semantic_candidates"]
    NOT in
        analysis["positions"]["PRESENT_EXISTS"]["provenance"][...]
        analysis["positions"]["ABSENT_ABSENT"]["provenance"][...]
        analysis["positions"]["ABSENT_EXISTS"]["provenance"][...]
        analysis["positions"]["PRESENT_ABSENT"]["provenance"][...]

This is a SEMANTIC TRUTH about retrieval provenance, not a
stylistic choice.

TASK 34 name: "Four-Position Semantic Retrieval"

    "semantic evidence"
    "Four-Position Semantic Evidence"

Rationale:
    evidence in Co-SMOS has a distinct epistemic status.
    semantic_candidates != evidence.

    semantic similarity

          |

          |
          v
    semantic evidence
