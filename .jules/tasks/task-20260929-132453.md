## Request

Co-SMOS v0.10 — TASK — PREVENT TEST TASK LEAKAGE

CONTEXT:
- Repo: Urania-order/jules
- Issue: Jules self-test creates persistent "Graph Task Test" tasks
- These accumulate in .jules/queue/pending/ AND .jules/queue/deferred/
- They are NOT real user tasks, but pollute the queue AND API /api/tasks
- Observed: leaked tasks in deferred/ appear in /api/tasks as PENDING
- Root cause: tests calling POST /api/tasks with request="Graph Task Test"

   grep -rn "Graph Task Test" .jules/ --include="*.json"

7. Test-mode signal?
   grep -rn "test_mode\|X-Cosmos-Test\|X-Test\|ephemeral" smos/api/main.py

DECISION:
   RECOMMENDED approach: X-Cosmos-Test header
   - Test code sends header "X-Cosmos-Test: 1"
   - POST /api/tasks sees header -> does NOT persist
   - Returns ephemeral task dict (no queue file, no state.json entry)
   - Production code (no header) -> persists normally

PART A — API: X-Cosmos-Test header

Modify smos/api/main.py POST /api/tasks:

    from fastapi import Header

    @app.post("/api/tasks", dependencies=[Depends(require_operator)])
    def create_task_endpoint(
        req: CreateTaskRequest,
        x_cosmos_test: Optional[str] = Header(None, alias="X-Cosmos-Test"),
        db: Session = Depends(get_db),
    ):
        is_test = x_cosmos_test == "1"
        if is_test:
            import uuid
            from datetime import datetime, timezone
            return {
                "id": f"test-{uuid.uuid4().hex[:8]}",
                "request": req.request,
                "status": "EPHEMERAL",
                "is_test": True,
                "created_at": datetime.now(timezone.utc).isoformat(),
            }
        # Normal path (existing behavior)
        return add_task_to_queue(req)

    #!/usr/bin/env bash
    set -euo pipefail

    count=0
    for dir in pending deferred; do
        for f in .jules/queue/$dir/*.json; do
            [ -f "$f" ] || continue
            if grep -q "Graph Task Test" "$f"; then
                rm "$f"
                count=$((count + 1))
            fi
        done
    done
    echo "Removed $count test task files"
