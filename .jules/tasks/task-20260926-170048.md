CONCLUSION CONTRACT (JSON schema)
============================================================

Canonical shape:

    {

      "text": "string",           # fallback for claim
      "confidence": 0.0,          # OPTIONAL, float in [0, 1]
      "detail": {...},            # OPTIONAL, free-form
      "context_ids": [...],       # OPTIONAL, list of int
      "evidence_ids": [...],      # OPTIONAL, list of int
      "provenance": {...}         # OPTIONAL, free-form
    }

Required:
  - claim (or text) must be non-empty.

Optional:
  - confidence: 0.0 <= x <= 1.0
  - all other keys: opaque (kept as-is)

Validation returns:
  (True, []) if valid
  (False, [list of error strings]) otherwise
