- created_at uses UTC (datetime.now(timezone.utc))
- Observed v1.2.8 (task-20260920-073119):
    id (local Kyiv): 07:31:19
    created_at UTC:  04:31:21
    Difference: 3 hours
- Fix: TASK_ID uses UTC (date -u)

ISSUE 2 — run-task.sh race (ERRATA-0037)
- run-task.sh polls top-3 sessions (head -3), not matching task_id
- Can match previous Completed session → false no-op
- Does not continue waiting if "In Progress"
- Does not check Result after jules-complete.sh

ISSUE 3 — run-task.sh cleanup safety
- If jules-complete.sh result = no-op → do NOT mark state.json as applied
- If result = error → do NOT mark applied
- Only result = applied → commit

PART 2 — run-task.sh race fix

1. Match session by TASK_ID (not top-3):
   BEFORE:
     LINE=$(jules remote list --session 2>/dev/null | head -3 | grep -E "Completed|In Progress|Planning|Failed" | head -1)
     STATUS=$(echo "$LINE" | awk '{print $NF}')
   AFTER:
     # Extract date part from TASK_ID (e.g., task-20260920-073119 → 20260920-073119)
     TASK_MATCH=$(echo "$TASK_ID" | sed 's/^task-//')
     SESSION_LINE=$(jules remote list --session 2>/dev/null | grep -F "$TASK_MATCH" | head -1)
     if [ -z "$SESSION_LINE" ]; then
         # Fallback: search by description (first 40 chars from task file)
         DESC=$(head -c 40 "$TASK_FILE" | tr -d '\n')
         SESSION_LINE=$(jules remote list --session 2>/dev/null | grep -F "$DESC" | head -1)
     fi
     STATUS=$(echo "$SESSION_LINE" | awk '{print $NF}')

2. Continue polling if In Progress (not break):
   if [ "$STATUS" = "Completed" ]; then
       echo "  ✅ Completed"
       break
   fi
   if [ "$STATUS" = "Failed" ]; then
       echo "  ❌ Failed"
       exit 2
   fi
   # In Progress / Planning → continue polling
   echo "  [+${ELAPSED}s] $STATUS"
   sleep "$POLL_INTERVAL"
   ELAPSED=$((ELAPSED + POLL_INTERVAL))

3. After max wait without Completed:
   if [ "$ELAPSED" -ge "$MAX_WAIT_SEC" ]; then
       echo "  ⚠ Timeout after ${MAX_WAIT_SEC}s — session still $STATUS"
       echo "  Run manually: ./scripts/jules-complete.sh --task $TASK_ID"
       exit 3
   fi
