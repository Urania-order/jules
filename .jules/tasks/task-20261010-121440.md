============================================================
DEFINITIONS — TWO DISTINCT MODES
============================================================

Historical replay:
    Execution of an analysis using its ORIGINAL inputs,
    versions, and necessary state snapshot.
    Goal: reproduce the ORIGINAL result.

Current-state rerun:
    Re-execution of the same analysis logic against the
    CURRENT canonical state.
    Goal: observe the CURRENT result.

These are DIFFERENT operations. The system MUST be able
to explain the difference, not to mask it as reproduction.
