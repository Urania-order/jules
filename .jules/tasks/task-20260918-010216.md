- Archive format: .jules/queue/reset-YYYYMMDD-HHMMSS.jsonl
  Line format:
    {
      "task_id": "...",
      "status": "...",
      "request": "...",
      "priority": N,
      "created_at": "...",
      "reset_at": "...",
      "scope": "...",
      "restored": false,
      "why": {
        "source_task": null,
        "proposal_origin": null,
        "proposed_by": null,
        "history_transitions": [...]
      }
    }
- Problem: After reset, tasks are archived but cannot be restored.
  No Undo in UI. No filter by status/date.

GOAL:
1. Add POST /api/queue/archive/undo {archive_ids: [...], confirm: "UNDO"}
2. Add POST /api/queue/archive/undo-filter {status, date_from, date_to, scope, search, confirm: "UNDO"}
3. Add GET /api/queue/archive (list archive entries, read-only)
4. Frontend: Reset Center panel with tabs:
    - Columns (existing reset buttons)
    - Archive (list with checkboxes)
    - Undo (filters + Undo Selected / Undo All Matched)
5. Shift+Click range selection for archive checkboxes

REQUIREMENTS:

1. GET /api/queue/archive
- Reads all .jules/queue/reset-*.jsonl
- Response: {entries: [{archive_id, task_id, status, request, priority, created_at, reset_at, scope, restored}, ...]}
- archive_id = "<file>:<line_number>" (unique per entry)
- Auth: operator/admin

2. POST /api/queue/archive/undo
- Request: {archive_ids: [...], confirm: "UNDO"}
- For each archive_id:
    - Find the line in reset-*.jsonl
    - If restored == true → skip (already restored)
    - Create new Task:
        * request = entry.request
        * priority = entry.priority
        * status = "PENDING"
        * why = entry.why (preserve)
        - history_transitions = entry.why.history_transitions +
            [{timestamp: now, status: "PENDING", message: "RESTORED from <archive_id>"}]
    - Add to state.json / tasks
    - Mark archive line restored: true (rewrite .jsonl line)
- Response: {status, restored: [...], failed: [...]}

3. POST /api/queue/archive/undo-filter
- Request: {status?, date_from?, date_to?, scope?, search?, confirm: "UNDO"}
- Find all archive entries matching filter:
    * status: entry.status == status
    * date_from: entry.reset_at >= date_from
    * date_to: entry.reset_at <= date_to
    * scope: entry.scope == scope
    * search: substring in entry.request or entry.task_id
- For each matching entry:
    - If restored == true → skip
    - Create new Task (same as undo)
    - Mark archive line restored: true
- Response: {status, matched: N, restored: [...], failed: [...]}
