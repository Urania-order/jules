4. AUDIT API — smos/api/main.py
============================================================

GET /api/audit/reports
    Read docs/audit-reports/INDEX.md.
    Parse rows.
    Return JSON list. For each report:
    - task_id
    - saved_at
    - decision
    - lines
    - head
    - report_url

GET /api/audit/reports/{task_id}
    Validate task_id against ^task-[0-9]{8}-[0-9]{6}$.
    Reject invalid with 400.
    Resolve path under docs/audit-reports/.
    Reject path traversal with 400.
    Return 404 if missing.
    Return text/markdown.

GET /api/audit/active
    Read .co-smos/state.json server-side.
    Return only:
    - active_task.id
    - active_task.status
    - active_task.started_at
    Do NOT return arbitrary fields.

GET /api/audit/trail
    Read docs/audit-reports/INDEX.md.
    Build trail from actual report metadata.
    Do NOT assume a planned chain.
    For each report, include:
    - task_id
    - decision
    - saved_at
    - head
    - links (if derivable from report content)
    Return JSON.

POST /api/audit/verify
    Run scripts/jules-audit-verify.sh using an argument array
    (no shell interpolation of user input).
    Parse output.
    Return JSON:
    {
      "status": "ok" | "incomplete",
      "total": N,
      "missing": [ ... ]
    }

POST /api/audit/save
    Body: {"task_id": "task-..."}
    Return 501 Not Implemented with:
    {
      "error": "clipboard access not available in browser",
      "cli_command": "./scripts/jules-audit-report.sh <task-id>"
    }
