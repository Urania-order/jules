============================================================
STEP 1 — SEMANTIC DISTINCTION (MANDATORY)
============================================================

Recipe answers:
    "How can X be done?"
Recipe is reusable procedural knowledge.

Learning Loop answers:
    "What did the system learn from an observed analytical process?"

Learning Loop connects:
    Analysis
        |
        v
    Conclusion
        |
        v
    Prediction
        |
        v
    Outcome
        |
        v
    Evaluation
        |
        v
    Learning
        |
        v
    reusable Recipe

Learning Loop is NOT itself a Recipe.

Create a lightweight CONTRACT module describing the relationship

    source_event_ids       -> list[DomainEvent.id]
    knowledge_ids          -> list[MemoryNode.id]
    evaluation_summary     -> dict
    created_at             -> datetime | None

Semantics (explicit constants + docstring):
    source_exposure_ids    = ContextExposure.id
    source_prediction_ids  = Prediction.id
    source_event_ids       = DomainEvent.id
    knowledge_ids          = MemoryNode.id

Do NOT create a persistent LearningLoop model in this task.
Do NOT create database migrations.

Purpose: establish SEMANTICS before PERSISTENCE.

FUNCTIONS in recipe_contract.py:

    - normalize_learning_evidence(evidence) -> dict

    - LEARNING_LOOP_DOC (module-level constant)
