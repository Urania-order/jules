DETECTION LOGIC (minimal, read-only)
============================================================

analyze_emergence(phenomenon_id):

0. Fetch phenomenon:
   phenomenon = db.query(Phenomenon).filter(id==phenomenon_id).first()
   If not found -> return EmergenceAnalysis with empty lists + note.

1. incoming = domain_service.list_into("phenomenon", phenomenon_id)
   outgoing = domain_service.list_for("phenomenon", phenomenon_id)

2. necessary_conditions:
   from incoming: relation_type == REQUIRES
   enrich with Constraint info if source_type == "constraint"

3. supporting_conditions:
   from incoming: relation_type in (ENABLES, SUPPORTS, AMPLIFIES)
   enrich

4. blocking_conditions:
   from incoming: relation_type in (BLOCKS, PREVENTS, SUPPRESSES)
   enrich

5. dependencies:
   from outgoing: relation_type == DEPENDS_ON
   enrich with target info

6. context_transitions:
   from outgoing: relation_type in (CHANGES_CONTEXT, CREATES_CONTEXT)
   target_type == "context"

7. possible_downstream_effects:
   from outgoing: relation_type in (CREATES_CONTEXT, CHANGES_CONTEXT, TRANSFORMS)
   NOTE: overlap with context_transitions is intentional; keep both —
   downstream_effects focuses on consequences, context_transitions on
   context changes.

8. PotentialPhenomenon integration:
   pp_records = db.query(PotentialPhenomenon).filter(
       PotentialPhenomenon.phenomenon == phenomenon.name
   ).all()
   For each pp:
     - required_conditions (JSON list) -> extend necessary_conditions
       with {"source": "potential_phenomenon", "potential_id": pp.id,
             "condition": item, "status": pp.status.value}
     - supporting_contexts -> extend supporting_conditions
     - blocking_constraints -> extend blocking_conditions
     - dependencies -> extend dependencies
     - expected_impacts -> extend possible_downstream_effects

9. unknowns:
   From ALL above collections, collect items where:
     - confidence < LOW_CONFIDENCE_THRESHOLD
     - OR evidence is empty list
   -> [{"source": "...", "reason": "low_confidence"|"missing_evidence"}]

10. Build EmergenceAnalysis:
    kind = "emergence_analysis"
    epistemic_status = HYPOTHESIZED (always)
    note = "Possibility analysis — NOT prediction. ..."
    NO predicted_outcome / forecast / probability / expected_date.
