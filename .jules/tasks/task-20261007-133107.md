4. SEMANTIC ADAPTER
============================================================

Create:
    smos/services/semantic_adapter.py

Minimal interface:

    from abc import ABC, abstractmethod
    from typing import List

    class SemanticAdapter(ABC):

        @property
        @abstractmethod
        def dimension(self) -> int:
            ...

        @abstractmethod
        def embed(self, text: str) -> List[float]:
            ...

        def embed_batch(
            self,
            texts: List[str],
        ) -> List[List[float]]:
            return [self.embed(text) for text in texts]

RULE:
    Adapter is abstraction boundary.
    It MUST NOT know about:
        Phenomenon
        Context
        Recipe
        Relation
        Prediction
        epistemic status

    It works with text -> vector only.
